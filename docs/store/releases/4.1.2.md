## 4.1.2 — Steadier through Nexus outages

Collections wait out Nexus outages, files Nexus holds back are named, and an outage page is no longer mistaken for a changed site.

- **Collections wait out a Nexus outage:** when Nexus Mods is unreachable behind Cloudflare (errors 525, 526, 527 and 530), a collection run now waits for it to come back instead of failing every file in turn.
- **Files Nexus holds back are named:** a file page where Nexus shows a virus-scan notice instead of the download now says so, in all 13 languages, and a collection run skips that file and carries on. A removed or hidden file is named the same way.
- **Firefox's blocked downloads are not retried:** a download Firefox's own protection stops is reported as blocked once, instead of being tried again.
- **No false "Nexus Mods changed this page":** an error page Nexus shows during an outage no longer triggers the page-changed notice.
- **Clearer error reports:** reports say more about why a download did not start, which setting was refused, and what Nexus answered.

Permissions are unchanged, and reporting stays off unless you turn it on.
