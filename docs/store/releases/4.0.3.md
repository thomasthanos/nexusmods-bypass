## 4.0.3 — Collections keep their tab, other mod managers and fewer failed files

This patch fixes the collection tab that closed after its first file (issue #45), adds a setting for mod managers other than Vortex (discussion #44), and fixes the errors 4.0.2 reported most.

- **A collection's tab stays open:** in Opera GX, a Vortex collection whose first file is "manual download only" closed its own tab after that file, so only one file was downloaded. *Close the extra Nexus tab* now closes only a tab that was opened just for that file. Any other tab stays open, and the file is still sent.
- **Another mod manager instead of Vortex:** if another mod manager opens `nxm://` links for you, turn off the new *Check that Vortex opens* (Settings → Downloads → Vortex). There is then no more "Vortex didn't open?" message, the extra tab closes as usual, and collections stop asking whether Vortex opened.
- **Fewer failed collection files in the browser:** the most reported error in 4.0.2 was a collection file failing with "no download link" on Chrome, Opera and Edge. Those files now download through the browser, as single downloads do.
- **Clear words for two problems on your computer:** when another extension (such as an ad or tracker blocker) or a privacy setting stops a request to Nexus, the error now says so and what to allow. When the browser cannot read the extension's own files, it says how to reinstall. Neither is sent as an error report any more.

Permissions are unchanged, and reporting stays off unless you turn it on.
