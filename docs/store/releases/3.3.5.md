## 3.3.5 — Download identity and collection recovery

This patch keeps download results tied to the requested file and makes collection recovery and local archive imports more reliable.

- **Nested download metadata:** links inside JSON or HTML metadata for another file are no longer accepted as fallbacks for the requested file.
- **Navigating away from a mod:** a link lookup that finishes after leaving the page no longer opens Vortex or starts a browser download from that old page.
- **API cancellation and rate limits:** cancelling a pending sign-in confirmation stops without a false sign-in error. A rate limit from that confirmation now delays subsequent API queries for the server's requested wait.
- **Restarting after Stop:** when an old download entry has been removed, a new run still waits if the browser cannot confirm that removal. A later readable download list can release the wait normally.
- **Other extensions' downloads:** an explicitly different extension owner is respected even when the Nexus host and file path match. Such a download is neither counted as this extension's completed file nor cancelled by Stop.
- **Unicode archive names:** importing Greek, Japanese, Korean or other non-Latin archive names no longer marks a different filename with the same numeric suffix downloaded. Equivalent composed and decomposed accented names match correctly.

Extension permissions are unchanged. Browser antivirus blocks remain terminal; the supplied network-failure report still has no proven cause.

The live report relay's extension-version baseline is 3.3.5. Its existing service bindings and secrets are preserved.
