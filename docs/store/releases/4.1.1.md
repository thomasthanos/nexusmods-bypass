## 4.1.1 — Collection folders and smoother downloads

Keep each collection revision in its own folder, with fixes for settings, background-download controls and long browsing sessions.

- **A folder for each collection revision:** turn on *Use collection name and revision as folder name* in Settings → Downloads → Browser downloads to save collections in folders such as `Collection Name (Rev 54)`. It is off by default and keeps your manual folder setting. Updates use the selected revision, and retries and resumed downloads keep the same destination. MO2 `.meta` files stay beside the archives. Available in all 13 languages. Opera uses the system Downloads folder for this option.
- **Settings keep saving after an error:** one failed save no longer stops later changes in the same settings window from being saved.
- **Stop works reliably in the popup:** background-download rows stay in place while their progress updates, so Stop clicks and keyboard focus are preserved.
- **Clear feedback for collection actions:** Download history, Clear history, Endorse and Track now explain a failure and let you try again.
- **Less page work and bounded memory:** fewer checks while browsing Nexus or leaving tabs in the background, and old API answers are cleared so long sessions use less memory and storage.
- **More reliable download windows:** repeat resumable downloads receive the correct archive name again, and links to other sites are no longer mistaken for Nexus Premium banners.

Permissions are unchanged, and reporting stays off unless you turn it on.
