## 3.3.3 — Reliable downloads and settings

This patch fixes download retries, collection startup, settings saves and error-report delivery. Both browser ZIPs are under **Assets** when this release is published.

- **Download retries:** cancelled, erased or deleted downloads can be retried immediately. Active downloads remain protected from duplicate starts, and stopped or replaced collection panels cannot restart delayed work or overwrite a newer run.
- **Nexus files and API:** archived-file metadata stays tied to its game and mod. Concurrent API calls keep independent cancellation, respect the longest rate-limit cooldown and retain Nexus's `Retry-After`.
- **Setup and settings:** late setup defaults preserve fields already edited. Rapid popup changes save in order and restore the last saved value after a failure. Switching to browser downloads retries only after the new setting saves. Importing downloaded filenames selects only missing files.
- **Wabbajack:** imports recognize the official `Nexus` download-state alias and escaped JSON property names, and cancellation stops archive identification cleanly.
- **Reports:** copy, save and send keep the report snapshot requested during edits. Pending automatic reports retain server cooldowns, debug-log clearing waits for pending writes, and relay retries share one delivery deadline.
- **Private dashboard:** notification counts include issue, review and test alerts; refreshed reviews preserve expanded text and keyboard focus; reconnecting retries unavailable Store data immediately. A push accepted before a database failure is not immediately sent again.
- **Diagnostics sign-in:** the live Cloudflare Access session now lasts 30 days after the next sign-in in the same browser or installed PWA, with MFA still required. Safari and the Home Screen app can use separate sessions. This is a live account configuration change; extension permissions are unchanged.

The relay's extension-version baseline is 3.3.3 and takes effect when that Worker is deployed.
