## 4.0.1 — Reliable collection retries and current diagnostics

This patch covers repeat collection runs with removed Nexus files, locally deleted archives, real Cloudflare challenges, server cooldowns and worker restarts. It also includes the unreleased browser-link fixes on main and the current diagnostics service.

- **Stop at a real challenge:** a Cloudflare response no longer silently skips up to three potentially valid files. The run stops at the first affected file, preserves completed-file history and keeps that file eligible after verification. Explicitly unavailable Nexus files still skip with pacing.
- **Keep server waits:** an explicit Vortex `Retry-After` is no longer shortened to the ten-minute backoff cap. A challenge with a cooldown remains a challenge and also records its wait. A replacement browser run waits for the shared deadline before requesting another file. Page-published shared deadlines retain their existing one-hour bound; a current Vortex tab keeps longer explicit waits locally.
- **Recover from outages:** Vortex gateway failures wait on the same file with bounded retries. An unreadable durable browser-job list retains a reconciliation alarm instead of leaving the run asleep.
- **Count the current collection:** history counts and the start dialog use only IDs in the current selection/revision. Older progress is retained. For files deleted from disk use **Re-download All**; a Vortex handoff is still recorded as sent, since the browser cannot verify Vortex's archive inventory.
- **Refresh live metadata:** complete published-revision responses now expire after ten minutes in memory and persistent storage. Old unbounded entries no longer revive removed-file metadata. Immutable game IDs remain cached separately.
- **Browser generator links:** the queue follows the generator's own validated intermediate link once, accepts only a real file response and retains throttling responses as waits. More Nexus notice kinds are named in redacted reports.
- **Diagnostics:** the current Worker includes automatic issue-fix tracking with its additive D1 migration. Deployment details and verification are recorded in the diagnostics README.

See [collection re-download recovery](https://github.com/thomasthanos/nexusmods-bypass/blob/main/docs/troubleshooting/collection-redownload.md) for the different recovery steps. Extension permissions and reporting consent are unchanged; genuine Cloudflare verification is required.
