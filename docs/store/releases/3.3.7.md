## 3.3.7 — Removed collection mods and misleading Cloudflare errors

Fixes a reproduced path matching the review about Cloudflare errors when downloading collection mods that Nexus has removed.

A removal page can still contain the requested `nmm=1` URL in a canonical or share link. The extension previously treated that URL as evidence that a download was available, ignored the explicit removal notice and asked the generator for a link. A Cloudflare response there replaced the useful removal reason.

The shared page classifier now honours Nexus's explicit removal/hidden-mod notice before these broad download-offer markers. Browser and Vortex collection flows stop after that page response and skip the unavailable mod without asking the generator. Existing queue pacing remains in place.

Regression tests cover both collection flows and verify that real Cloudflare challenges still take priority, a rendered mod page stays usable, and adult-content notices are not treated as deletion. The review contains no diagnostic log, so this release fixes the reproduced failure path without claiming to eliminate genuine Cloudflare verification.

Extension permissions and reporting choices are unchanged.

The live report relay's comparison baseline is 3.3.7; its other bindings and secrets are preserved.
