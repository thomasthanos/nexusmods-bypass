## 4.0.2 — Firefox file names, Cloudflare checks in collections and clearer errors

This patch fixes the Firefox problems reported in issues #41, #42 and #43. It also lets collections use the Cloudflare fallback, explains more of the errors users see most, and makes the extension's small dialogs fit narrow windows.

- **Firefox names newer files again:** since 4.0.0, Firefox saved Nexus's newer files under a code such as `1895579d-e5d5-…` with no extension. They are now named `<mod name>-<file id>`, with the extension the file really has (`.zip`, `.7z` or `.rar`). A download folder and Mod Organizer 2 `.meta` files work for them too. Chrome, Edge and Opera were not affected.
- **Import finds those files:** *Import downloaded mods* now recognizes the files Firefox saved under such a code, with or without an extension added by hand. After the update, run *Import* again and only the files you really are missing are left to download.
- **Small collection files download in the browser again:** a browser collection run failed every newer file under a kilobyte with "no download link". Those files now download.
- **The Cloudflare check in collections:** *Open page for a browser check* is on by default, now for collections too. When Nexus asks a collection run to confirm you are human, a Nexus page for the check opens in a new tab. Complete the check there and start the download again: it carries on from the same file. Turning the setting off now asks first, in plain words, and bug reports say clearly whether it is on.
- **What Nexus says where a link should be:** when a file page shows a notice of its own instead of the download (the most reported error, mostly on Opera with Vortex), the error dialog and the collection log now quote that notice, so you can see why. The quote stays in your browser.
- **A fairer wait for download links:** *Wait for a download link* is now at least 15 seconds, a saved shorter wait included. With 5 seconds, links that Nexus gave a moment later failed.
- **Dialogs fit narrow windows:** the extension's questions, alerts and error dialogs wrap their title and buttons in a phone-sized window or at high browser zoom, in every language.

Permissions are unchanged, and reporting stays off unless you turn it on. Nexus's Cloudflare check is never bypassed: you complete it yourself.
