## 4.1.3 — JDownloader and steadier collection downloads

- **Optional JDownloader handoff.** Turn on **Send browser downloads to JDownloader** in Settings → Downloads. It supports single mods and collections. Turn off autostart to review links in the LinkGrabber first. The run summary counts accepted links as sent.
- **Send only the remaining files to Vortex.** **Skip sent, send rest** in collection history leaves out files already sent, including from Mandatory and Optional runs. **Resend missing** remains available if you need to send those links again.
- **More reliable download recovery.** Collection queues wait on the current file during a Nexus outage. Vortex keeps the original timeout when the fallback page cannot supply a link. File-page checks give late download controls one more chance to render.
- **Clearer reports.** **Add details** opens the selected incident beside the source tab and shows a retry message if the report page cannot open. The diagnostics dashboard shows recurring issues in their historical date ranges and identifies the step that failed in scheduled jobs.
