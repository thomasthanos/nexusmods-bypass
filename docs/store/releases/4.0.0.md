## 4.0.0 — Resumable downloads, real file names and a faster start

4.0.0 brings Nexus's new resumable downloads into the extension, keeps the real names of Nexus's newer files, starts several seconds sooner on every Nexus page, and fixes the errors users reported most. Every change was checked on Nexus itself on 2026-11-01, with a signed-in account: single files in five games, Vortex links, two whole collections and large files.

**Resumable downloads and large files.** For a file over 500 MB, Nexus now asks *Standard download* or *Resumable download*. The extension lets Nexus ask, in its own look, from the Files tab, the requirements window and *Auto-start* alike. *Standard download* starts the file through the extension; a resumable download stays with Nexus, shown in the extension's own panel with *Pause*, *Resume*, *Cancel* and *Direct download instead*. A large file's page that never finishes loading no longer leaves only the file's name on screen: the file's line has a **Download** button of its own when *Hide ads and Premium panels* hides Nexus's.

**Real file names.** Newer Nexus files have no name in their download link, and the extension saved them as `<mod>-<file id>.zip`, 7z archives included. The browser now names them from Nexus's answer. With a download folder or Mod Organizer 2 `.meta` files set, Chrome, Edge and Opera put them in that folder under that name, with the `.meta` beside it; in Firefox such a file keeps Firefox's own name and place. *Import downloaded mods* recognizes these names, and those older versions gave.

**Faster and lighter.** The extension starts a few dozen milliseconds after a page arrives instead of 6–10 seconds later, hides ads before the page is drawn, answers the ad-blocker notice by itself, and asks the official API less.

**Vortex.** Vortex links are read from the file's page, as Nexus's own button does, with one request fewer per file and no browser link drawn on the way.

**Collections.** The end-of-run summary lists the collection's files that are not on Nexus (off-site, linked, or bundled in the collection), says *downloaded* after browser downloads, and keeps what a run did before a page reload.

**Clearer errors, fewer false reports.** A visitor Nexus does not see as signed in is told to sign in, instead of "No Vortex link"; a file the mod no longer has is *file not found*, one under moderation says so, and none of these is sent as an error report. Downloads blocked by the browser, security software or a full disk are no longer reported as bugs. Mod Organizer 2 `.meta` files are written in Firefox again, with the file's version also for archived files.

**Also.** Patreon joins the ways to support the project, and the collection panel's menus work with screen readers.

Extension permissions and reporting choices are unchanged.
