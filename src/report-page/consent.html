If the extension fails, it can send a small technical report to the developer's private Discord channel. You will not need to report each error yourself.

  • Includes the error, extension and browser versions, action and page type. No page content, download history, settings or account details.
  • Off until you enable it. You can turn it off at any time in Help & Bugs → Send bug report.

Your browser may ask for permission to send reports. Allow it to finish enabling this feature.
