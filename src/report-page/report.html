Nothing is sent until you press Send. Below is exactly what will be sent: names, e-mail addresses, file paths, cookies, tokens and link parameters are removed.

        
Automatic error reports
Off by default. Sends only technical errors, extension and browser versions, action and page type. Repeated errors are grouped; up to ten reports a day. No page content, history or settings. Failed sends retry automatically.
Separate choice, off by default. Also sends public file IDs and up to 20 redacted debug lines from the same page type in the two minutes before an error, if logs were recorded. No page content, account details or signed links. Sent to the same private Discord channel. Turning this off clears pending reports.
Separate opt-in, off by default. Requires automatic error reports. Stores sampled technical errors, extension/browser versions, OS and a random installation hash in the developer's private dashboard, with Discord/push alerts. Extra debug lines require the separate extra diagnostics choice. No download-success telemetry. Turning this off deletes unsent dashboard reports.
