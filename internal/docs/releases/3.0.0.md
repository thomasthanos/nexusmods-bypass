## What's new

- **Downloads that keep moving.** Duplicate-start prevention, correct file selection, smallest-first queues, clearer skip reasons and smarter recovery.
- **Better collection controls.** Official Nexus API integration, revision/update badges, optional curator policies and click-only Endorse/Track actions.
- **A UI that fits.** Responsive panels from 720p to 4K, keyboard-friendly controls, themed scrollbars and all 13 interface languages.
- **Reports with useful context.** A redesigned report workspace, exact redacted previews, live debug logs and clearer Discord / GitHub reports.

> **Release checks passed:** build/regression checks, lint, 32 browser tests, live validation of 12 API queries and the final GitHub CI gate. Firefox package lint: **0 errors / 15 warnings**. Details and limitations below.

<details>
<summary><strong>Full feature notes</strong></summary>

### More reliable downloads and collection queues

- Smallest-files-first ordering for browser and Vortex queues, with unknown sizes kept last and a setting to disable sorting.
- Removed, hidden, unpublished or missing mods are skipped with a reason rather than repeatedly retried; isolated Cloudflare answers no longer stop a whole collection.
- One owner per download click, shadow-DOM-aware interception, per-file/method claims and a background duplicate-download safety net.
- Requirements-modal downloads stay pinned to the file originally selected.
- Reliable collection-panel mounting after late hydration and in-page navigation.
- Cause-specific retries for browser interruptions, exponential backoff/jitter for link resolution and a minimum Vortex handoff gap.
- Confirmation before batch runs containing more than 50 mods.

### Official Nexus API and collection controls

- Documented v2 GraphQL integration for collections, revisions, game IDs and mod-file lists, with shared throttling, HTTP 429 handling, caching and an outage fallback.
- Revision/update badges and an optional curator update-policy setting; exact pins and unknown policies preserve the selected file.
- Click-only Endorse/Track actions with refreshed viewer-state caching.
- More accurate sign-in/access errors, including adult-content access restrictions.
- Wabbajack archive identification through local MD5 calculation; only the hash is sent to the lookup service.

### Responsive interface

- Fluid extension panels, popup and onboarding layouts designed for 720p through 4K and 100–150% zoom.
- Popup-width correction, themed scrollbars, keyboard-accessible custom dropdowns, focus/hover states and reduced-motion support.
- Updated interface strings across all 13 supported languages.

### Redesigned reports and live debugging

- A dedicated report workspace with problem categories, summary, reproduction steps, expected results and a readable diagnostics overview.
- Send, copy and save use the same reviewed/redacted JSON snapshot; GitHub provides a prefilled fallback.
- Relay health checks and specific messages for configuration, permission, connection, rate-limit, payload-size and server failures.
- Relay permission is requested directly within the Send click so the browser can display its permission prompt.
- A separate live debug-log page with level filtering, search, follow mode, clear and text/JSON export; logging remains opt-in.
- Discord delivery includes severity colouring, page context, clamped embeds and the complete JSON attachment.
- Shared KV-backed relay rate limiting and ten-minute deduplication of identical automatic errors. Automatic reports remain off by default.

### Diagnostics and development safeguards

- Centralised Nexus selectors and page/API-change diagnostics with fewer false positives and less recovered-error noise.
- Allowlisted log markup, stricter message-sender checks and broader redaction of tokens, cookies, e-mails and local paths.
- Locale/regression fixtures, browser-layout coverage, Firefox package checks, permission-diff monitoring and schema-watch tooling.

This is a cumulative milestone: some improvements were previously shipped in the 2.x line, while others are new since the last published GitHub release.

<summary><strong>Installation, privacy and upgrade notes</strong></summary>

- **Chrome / Edge / Brave / Opera:** `nexus.mods.bypass-3.0.0.zip`. Extract and load the folder as an unpacked extension.
- **Firefox 140+:** `nexus.mods.bypass-3.0.0-firefox.zip`. Load through `about:debugging` as a temporary add-on; permanent installation still requires a signed store release.
- The existing extension identity is retained. Updating the same installed extension keeps its locally stored settings/history; a separately installed copy may use different storage.
- Report-relay access remains an optional permission requested when sending a report or enabling automatic reports.
- This GitHub release does **not** publish or update the Chrome, Edge or Firefox store listings.
- Vortex delivery confirms link handoff, not completion inside Vortex.
