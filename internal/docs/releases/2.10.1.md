## What's new

This release includes #13 and #14, plus fixes found during the final review.

- **Official Nexus API:** collection details, revisions, game IDs and file lists use the documented v2 API, with caching, batching and an outage fallback.
- **Collection controls:** newer-revision and update badges, optional curator update policies, and click-only Endorse/Track buttons.
- **Reliable downloads:** fixes for duplicate downloads, collection panels that needed a reload, false sign-in warnings, and retries after interrupted browser downloads.
- **Responsive panels:** settings, the collection deck, mod picker, popup and welcome page fit 720p through 4K screens and 100–150% browser zoom.
- **Diagnostics:** opt-in debug logs, a report preview with broader redaction, and an optional report relay. Automatic reports remain off by default; the relay requires separate deployment.
- **Archive identification:** Wabbajack imports can identify local archives by MD5; only the hash is sent.

## Final review fixes

- Fallback API calls consume the same request budget and honour `Retry-After` when the router returns HTTP 429.
- Successful Endorse/Track actions refresh cached viewer state. Older in-flight responses cannot put stale state back.
- Concurrent API queries share one cache initialization, avoiding duplicate storage reads and lost cache entries.
- Unknown curator update policies keep the listed file and make no unnecessary file-list request.
- GraphQL failures are no longer treated as valid empty file lists.
- Firefox package validation works when older release ZIPs are still present in `dist/`.

Regression tests cover these cases. Publication requires lint, all regression suites, Firefox package lint, 26 Chromium layout/interaction tests and live schema validation to pass.
