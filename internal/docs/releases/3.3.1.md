## 3.3.1 — Mobile diagnostics and logs

The private diagnostics dashboard fits phone screens better, recovers safely when the app is reopened, and can receive new extension error reports after a separate opt-in. Downloads work as in 3.3.0. Both refreshed browser ZIPs are under **Assets**; the version remains 3.3.1.

- **Mobile dashboard:** date fields, selects and filters stay inside the screen. Clearer spacing, full-width filter actions, readable controls and a bottom navigation bar that reserves the iPhone safe area make Overview, Issues and Settings easier to use.
- **Session recovery:** returning to the app refreshes the current view. Responses from cancelled requests cannot lock a newer view. **Check session** reconnects only after a fresh authenticated health check; an expired Access session still clears private data and requires sign-in.
- **Safari notification fix:** registering a device or sending a test no longer sends `Origin: null` under the dashboard's privacy policy. The server's origin check remains enabled. A blocked request shows an operation error instead of incorrectly signing you out; authentication failures include a safe diagnostic reference.
- **Private error reports:** the new **Private diagnostics dashboard** option (`PrivateDiagnostics`) is off by default and requires automatic error reporting. It sends new, redacted technical errors through the existing relay to the private dashboard, with browser/OS information and a hash of a randomly generated installation seed. Existing reporting choices alone do not enable it. Extra debug lines still require the separate extra-diagnostics choice.
- **Private service:** the <a href="https://github.com/thomasthanos/nexusmods-bypass/tree/main/diagnostics"><kbd>diagnostics service</kbd></a> runs on its custom HTTPS domain with an EU D1 database and owner-only Cloudflare Access login with MFA. The relay uses a fixed Worker service binding to deliver opted-in reports without adding extension host permissions.
- **Clearer discussions:** *Ideas* and *Q&A* have more specific prompts, topic choices and submission checklists. *General Discussion* and *Show and Tell* now have their own forms. Open the <a href="https://github.com/thomasthanos/nexusmods-bypass/discussions"><kbd>Discussions page</kbd></a> to share an idea, ask for help or show your setup.
- **Repository maintenance:** documentation, release-note links, badges and SVG assets have been refreshed, with updated contribution and security guidance and a new social preview. Development dependencies have also been updated.

<details>
<summary><strong>Repository & reports</strong> — deployment and privacy</summary>

- Enable **Automatic error reports** and then **Private diagnostics dashboard** in the extension's Diagnostics settings or report page to send future faults to the dashboard. Reports already sent to Discord are not imported. A newly opted-in incident uses one automatic reporting destination, avoiding duplicate Discord reports.
- Heartbeat and download-attempt telemetry is not enabled or sent by this client. Success/fallback rates remain unavailable until real attempt data exists; error reports are not treated as download attempts.
- The diagnostics Worker and relay must both run the updated code, with the relay's `DIAGNOSTICS` binding pointing to `nexusmods-diagnostics`. The relay baseline is 3.3.1; deployed secrets, keys and database data are preserved during updates.
- Existing 3.3.1 installations need the refreshed ZIP; keeping the same version number does not trigger an automatic extension update.
