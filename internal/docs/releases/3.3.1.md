## 3.3.1 — Diagnostics online

The private maintainer diagnostics dashboard is now deployed on Cloudflare, and the repository has clearer discussion forms and refreshed documentation. Downloads work as in 3.3.0. Both browser ZIPs are under **Assets**.

- **Private dashboard online:** the <a href="https://github.com/thomasthanos/nexusmods-bypass/tree/main/diagnostics"><kbd>diagnostics service</kbd></a> runs on its custom HTTPS domain with an EU D1 database and owner-only Cloudflare Access login with MFA. Its mobile PWA can be added to the home screen. The existing extension still sends reports to the legacy relay; the new diagnostics and heartbeat integration is not included in this release.
- **Clearer discussions:** *Ideas* and *Q&A* have more specific prompts, topic choices and submission checklists. *General Discussion* and *Show and Tell* now have their own forms. Open the <a href="https://github.com/thomasthanos/nexusmods-bypass/discussions"><kbd>Discussions page</kbd></a> to share an idea, ask for help or show your setup.
- **Repository maintenance:** documentation, release-note links, badges and SVG assets have been refreshed, with updated contribution and security guidance and a new social preview. Development dependencies have also been updated.

- Deployment configuration and installation guidance are in the <a href="https://github.com/thomasthanos/nexusmods-bypass/blob/main/diagnostics/README.md"><kbd>diagnostics README</kbd></a>. The dashboard initially has no extension data; client integration and consent are separate work.
