## 3.3.0 — Ideas and diagnostics

Ideas and questions now open GitHub Discussions, where others can vote and help. This release also adds the source for a private diagnostics dashboard for maintainers. Both browser ZIPs are under **Assets**.

- **Ideas and questions:** in the popup's **Report on GitHub** menu, *Idea or suggestion* starts an *Ideas* discussion and *Question* starts a *Q&A* discussion. The in-page settings have a **Suggest an idea** link beside **Report a bug**, in all 13 languages. Bug reports still open an issue with the diagnostic report.
- **Private diagnostics source:** the independent <a href="https://github.com/thomasthanos/nexusmods-bypass/tree/main/diagnostics"><kbd>`diagnostics/` package</kbd></a> includes a Cloudflare Worker API, D1 storage and a mobile PWA protected by Cloudflare Access. It groups sanitized reports, identifies repeated or regressed faults, compares release health, and shows report timelines with copyable AI debug context. Discord and Web Push delivery and device management are included.

<details>
<summary><strong>Repository & reports</strong> — setup and privacy</summary>

- The new diagnostics service requires its own domain, Access application, database, secrets and deployment. It has not been deployed or connected to extension reporting; the existing relay remains the extension's reporting destination. Setup and consent requirements are in the <a href="https://github.com/thomasthanos/nexusmods-bypass/blob/main/diagnostics/README.md"><kbd>diagnostics README</kbd></a>.
- The relay source baseline moves to 3.3.0: after that Worker is separately redeployed, reports from 3.2.0 and older still arrive but no longer ping the maintainer.
- Extension permissions and opt-in reporting are unchanged. The new diagnostics package does not enable heartbeat telemetry in the extension.
- The repository's issue chooser sends ideas and questions to Discussions, and new discussions are announced on Discord.

</details>
