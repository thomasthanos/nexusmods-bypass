# 3.1.2 — Download recovery and clearer error reports

When Nexus's download API cannot be read, the extension now tries its existing download generator instead of stopping immediately. Successful recovery produces no error report. Sign-in, verification, access denials, missing files and rate limits are not bypassed.

Page checks recognise rendered mod content and JSON-backed Nexus download components without requiring the old `#section` wrapper or `file-id` attribute. Missing account controls are reported as unknown sign-in state, and pages still loading are skipped.

The collection download panel also mounts in rendered `#mainContent` or semantic main content when Nexus's legacy container classes are absent. It recovers after a same-route re-render. Collection data loading and the bounded panel-mount retries do not produce premature page-change reports; a mount point still missing after recovery remains reportable.

Repeated faults are grouped hourly; repeated network and timeout failures are grouped every six hours. The separate Worker update applies these cooldowns to older clients too, and limits automatic mentions to once per fault/version in 24 hours. Manual reports still notify normally. Report counts refer to occurrences in that client report, not unique users or a server-wide total.

Network diagnostics include the request method, a fixed route category and whether the failure occurred before a readable response or while reading it. They do not identify a CORS, Cloudflare or connection failure without evidence, and contain no request URL, query or credentials. Security-blocked downloads are clearly labelled without weakening browser or antivirus checks.

Automatic reporting remains opt-in with no additional manifest permissions. Opting out clears pending automatic reports.

The destination secret, maintainer configuration, CORS origins and KV binding were preserved. Live health, Chrome/Firefox extension-origin preflights and an invalid-schema CORS response passed. No live Discord test message was sent; formatting and cooldowns were verified offline.
