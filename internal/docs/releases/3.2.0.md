## 3.2.0 — The whole archive

Every file in a mod's file archive can be downloaded again, and Mod Organizer 2 now knows which Nexus mod a file is, whether you downloaded it from the mod's page or from a collection. Both browser ZIPs are under **Assets**.

- **Archived files:** every file in a mod's file archive gets its own *Mod manager download* and *Manual download* buttons; only the top one did. Files that show up after the page has loaded get them too, and a file Nexus holds back or its virus scan flagged keeps what Nexus shows. Reported in <a href="https://github.com/thomasthanos/nexusmods-bypass/issues/33"><kbd>#33</kbd></a>.
- **Mod Organizer 2 `.meta` files for every mod:** *Write Mod Organizer 2 .meta files* (off by default, now under **Downloads**) also covers mods downloaded from their own page, not only collection files. With it, MO2 shows the mod's description and its Nexus link opens the mod's page. The file also names the mod, and Fallout: New Vegas and Enderal SE go by the names MO2 uses for them.
