## 3.1.6 — Clearer reports, optional diagnostics

Smaller Discord messages, more useful technical details when you choose to share them, and clearer separation between errors, warnings and older extension versions. Both browser ZIPs are under **Assets**.

- **One compact summary:** automatic reports show the action, technical cause and incident details once. The JSON is attached with its preview hidden; manual reports keep the exact reviewed JSON.
- **Clear severity and versions:** errors are red, page/schema and network warnings are amber. Older clients remain supported and are labelled separately—not assumed fixed or mixed with another build.
- **Your choice stays yours:** extra diagnostics have a separate toggle, **off by default**, translated into all 13 languages. Existing automatic-report consent does not enable it. **No** still means no automatic transmission.

<details>
<summary><strong>Diagnostics & safeguards</strong> — what is included and what stays private</summary>

- With extra consent, include at most **20 redacted log lines** of the same page type from the **two minutes before the incident**, and public expected/received file IDs when available. This does not turn on debug recording; entries are not guaranteed to come from the same tab.
- Automatic attachments allow only supported technical fields—not settings, contact details, page content, account details or signed download URLs.
- Turning reports off clears pending payloads and cancels in-flight requests where possible. Daily budgets and duplicate-suppression history stay intact, so toggling consent cannot bypass limits.
- Grouped incidents retain the latest file IDs and capture logs at the error's time, rather than collecting unrelated logs at delivery.
- The relay keeps the same URL, private Discord destination, maintainer mention and shared rate-limit binding. Extension permissions are unchanged.

</details>

**Checked locally:** ESLint, all 21 regression suites and package checks, 81 Playwright tests in Edge, and all 12 operations against the live Nexus schema. Firefox package lint reports **0 errors** (27 warnings). A local snapshot-processing microbenchmark measured a 0.13 ms median for a 400-line buffer; this is not a whole-extension CPU/RAM measurement.

This patch improves reporting and privacy controls; it does not change Nexus file-ID resolution or Vortex download matching.
